# 深入玩法

先选一个世界，再选出生抽样。出生人数抽样偏向出生率较高的地区；人口抽样的分布不同，但都从零岁开始。过去可选 1970、1990、2010，今日使用 2023 年统计起点，未来是 2050 年游戏假设。「任意世界」从这五个世界中抽取。选择实际家乡后，出生登记会比较两地预期寿命和人均 GDP；设置会自动记忆。

## 先完整走一生

第一次建议选 30 分钟、关闭自动模式，保留默认开启的「人生停顿」。用「下个选择」跳过等待，读完选择再继续。5、15、30、50、70 岁会有私人提问，可以填写或跳过。游戏工具菜单可随时切换停顿。只有主动公开结束后的摘要才会上传；这些回答不公开。

两岁会遇见四选一的童年抉择，四岁留下成长记录，七岁选择兴趣。六岁起可以改变年度重心：在学儿童五项、未上学儿童四项、大学生与一般就业成年人六项。成年后进入「花钱 · 投资」，消费按项目冷却，不共用三次年度活动额度；旧版年度活动仍保留在单独展开的面板中，投资不消耗活动次数。

「下个选择」会快速逐年走过，重要告别也可能停下。点击速度会恢复播放。自动模式先高亮约三秒才确认；直接选其他按钮会立即采用你的选择，点击卡片标题可取消当次预选，收起卡片会停在原年，之后可重新展开。手动改变年度重心会取回控制。

手机上先显示场景、四项简要状态和人生记录，再显示年度专注、详细状态和身份信息。速度与「下个选择」保留在顶部，更多工具收进「…」菜单；按 Escape 可关闭菜单。状态、身份、家庭、同行者、年格和曲线共六个面板可点箭头收起或展开。

## 三条可尝试的路线

| 路线       | 具体尝试                                                         | 观察什么                                         |
| ---------- | ---------------------------------------------------------------- | ------------------------------------------------ |
| 成长与迁居 | 童年专注学习，成年后学习、求职、积累现金；知识达到 20 后尝试迁居 | 教育、经验、职业等级与收入；迁居第一年的适应成本 |
| 家庭与陪伴 | 经常专注陪伴，探望父母，经营伴侣关系，安排孩子的学习             | 父母衰老、伴侣亲密度、孩子成长与家庭开销         |
| 稳定与储备 | 保留现金，将一小部分配置到两类组合，遇到住房选择时比较现金流     | 现金与净资产的差异、年度波动、房贷利息与本金     |

这些是探索游戏规则的路线，没有唯一最优结局。低收入起点可以用免费活动维持关系和快乐；选择工作的时机、教育支出和迁居成本会改变可用现金。

## 成人系统怎样相互影响

- 职业：知识、教育与职业等级共同影响收入；有机会每五年晋升。主动学习增加知识和经验，求职有成功概率，移居会出现适应期。
- 财务：净资产 = 现金 + 两类投资 + 房产 − 房贷。消费可在本局限额内直接借款，现金可变负；无收入学生不能任意透支。聚餐和体检冷却一年，五种课程共用两年冷却。稳健组合每年模拟增长 2.5%，波动组合可能亏损；房贷有利息和年度还本。所有金额均为游戏中的 PPP 国际元。
- 关系：父母会衰老，朋友和伴侣关系会变化，孩子有出生、入学和成年节点。陪伴能改善亲密度。迎接孩子会增加开销。
- 迁居：18–75 岁、知识至少 20、现金足够、完成当前选择后，每年可迁居一次。出生地不会改变，生活与收入基数改用现居地。规则不代表真实签证资格。
- 保障：成年后可购买健康保障，每年收取费用，降低普通疾病与体检的费用。它不会消除衰老或保证结局。

消费面板打开时会暂停年份、保留此前的播放或暂停状态，完成消费后保持打开并刷新余额和冷却。求职后等待后续岗位；介绍对象最多三次；打听国外工作之后才有出国、当地工作和居留选择。办理迁居仍需要现金和知识，不代表真实签证规则。自动模式代选并略过停顿问题，适合观察一段人生，但不替你购买消费、投资或申请迁居。

点击人生记录的一行可展开收藏按钮，再点星标保存；键盘也可操作。抉择窗口可先收起，之后从待选提示重新打开，也可在窗口内交给自动。

## 结束后继续探索

1. 结尾按最后时刻、回忆、告别等阶段播放，回忆数量随本局变化；点两次跳过可进入全页死亡纪录，之后可重播。少年纪录省略成年时间与人生纹理；成年纪录按实际年度记录回顾重心、最幸福年份和收入年份。给这一生留句话，保存卡片或导出 JSON。未完人生也能从「我的人生」继续。
2. 选择「将摘要留在公共纪念馆」，先看预览，再明确公开。别人可以点灯、留言和分享链接。公开内容是虚构角色摘要，不含完整档案或私人问答。
3. 原浏览器保存撤回凭证，可以撤回摘要及其烛光、留言。JSON 档案会携带该凭证；换设备可导出后导入。档案包含私人记录和撤回权限，请勿公开分享。
4. 再选一个年代或抽样方式。也可以分享出生种子，让朋友遇见同一个起点，比较各自的选择。
