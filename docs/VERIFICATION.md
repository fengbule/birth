日期：2026-10-25（Asia/Shanghai）。本地 Node.js 24.14.1、Chromium 147.0.7727.15（Playwright）；生产 API 使用 Node.js 24 Alpine 容器。

## 规则与数据

`npm test`：24 项全部通过，零失败，约 90 秒。覆盖真实数据与汇总值排除、出生确定性、50,000 次抽样分布、全部选择、经济状态、旧档案兼容、畸形导入拒绝、活动次数限制、投资收支守恒、迁居条件和人生停顿。

基础与扩展各模拟 1,000 段完整人生，另以独立控制随机数模拟 10,000 段混合年代人生，共 12,000 段。每步检查状态，定期 JSON 往返重载，均能结束。压力测试覆盖全部 217 个出生地区及 63 个选择分支，成功执行 357,812 次主动活动、10,732 次迁居。前 217 个压力样本逐国固定起点，其余按出生/人口权重抽样；这些数字不是原站覆盖率。

另执行 5,000 次买卖，确认净资产守恒，事件上限为 2,000，选择与收藏记录保留、事件 ID 不重复、存档仍可重载。拒绝缺失资产/职业字段、非法小数年份、未来事件年龄及不可能的等待状态。30/60/90 分钟与默认 60 分钟通过检查，旧档案 5/15 分钟兼容。

历史数据有效覆盖：1970 年 216 地区，1990、2010 年各 217 地区；今日截面为 2023 年 217 地区。2050 年情景明确标注为游戏假设。

API 测试覆盖来源校验（含代理主机名）、发布与字段校验、公开响应不含管理凭证、点灯去重、留言、数据库关闭重开、撤回鉴权及级联删除。同毫秒发布的 25 条记录可跨页完整读取；SQLite 一致性备份通过完整性与记录数校验。HTTP 边界检查覆盖损坏 JSON、错误内容类型、16 KB 大小限制、非法来源、分页参数、路径穿越及含 SQL 字符串的文字；同一访客 12 个并发点灯请求只累计一次。超过人生结束年龄的公开事件被拒绝。
