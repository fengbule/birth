## 实际对照

直接打开原站英文、中文与部署站；1440×1000 桌面和 390×844 手机分别使用新浏览器上下文。原站实际走至 65 岁结局，部署版至 92 岁结局；另操作成年消费、借款、求职、收藏、手机折叠、结尾重播与跳过。随机身份不同，不作寿命数值的逐项等价判断。实质差异与修复列表见 [LIVE-COMPARISON.md](LIVE-COMPARISON.md)。

新增 `tests/browser_compare.py` 实际采集两站八对画面，生成可叠加的 HTML 对照与布局 JSON；本地采集完成，四个浏览器上下文的页面错误均为空。原站实际版本为 v0.8.38，成功采集不代表等价验收通过。

## 修复回归

本地 `tests/browser_presentation.py` 六种宽度（360、390、768、1280、1440、1920）通过，页面运行时错误为空。验证出生四个同行者、婴幼儿隐藏专注、概率条比例、动态年格、整行展开与收藏、键盘展开、六个手机面板折叠、560px 抉择窗口及收起重开、卡内转自动；同时回归设置记忆、世界、主题、延迟地图、结尾重播/跳过及归档不重复。
