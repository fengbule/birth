# v4.0.0 互动小镇验收

日期：2026-10-26，Asia/Shanghai。Node.js 24.14.1、Chromium 147。上一版记录保存在 [v3.1 验收](VERIFICATION-v3.1.md)。

## 本轮变化

按用户的新方向，将主界面改为地图与当前经历并排；手机上地图在前、故事在后。原创像素小镇含九个逐步开放的地点、年龄变化的主角、行人和活动道具。初始只显示家与当前故事；旧经历、身份、同行者、年格与存活曲线收在折叠区域。

活动分为出发、沿路移动、到达行动、完成结算、阅读结果。开始时不扣钱、不加属性；完成时重新核对资格与冷却。暂停冻结过程，取消或途中刷新不提交未完成活动。免费日常和原活动共用三次年度额度；消费沿用已有冷却与限额借款。每段故事逐一阅读，自动模式和快进仍可连续推进。

此版主动采用新的布局与节奏，不宣称与原站视觉或全部规则等价。原站实际走查与限制保留在 [体验对照](FEEL-COMPARISON.md) 和 [差异审计](PARITY-AUDIT.md)。

## 本地实测

- `browser_town.py`：390、1440 两种宽度，从婴儿经可见控件走到成年。活动完成前无收益，暂停后仍无收益；取消不计次数，结果等待阅读；人物沿路到学校、学校有读书动作；地点按年龄解锁，档案与日志折叠；收藏刷新后保留；地图聚餐完成后才扣钱，途中刷新取消购买，完成后按冷却禁用。页面错误为 0。
- `browser_presentation.py`：360、390、768、1280、1440、1920 六种宽度无横向溢出。桌面并排、手机上下；键盘展开收藏、人物档案与同行者、深色、设置恢复、菜单 Escape 和延迟世界地图恢复通过。
- `browser_bulk.py`：12 个地区、今日/1990/2010/2050 世界、四种宽度，完整走完 12 条人生。消费、课程共用冷却、求职与迁居事件、自动预选接管、收藏刷新、结尾、纪录与重播通过，页面错误为 0。
- `browser_smoke.py`：完整人生止于 76 岁，PNG、私有 JSON、恢复、共享种子、自动走到八岁、导入合并通过。
- `browser_deep.py`：1990 年私人停顿、关系、投资、迁居、纪念馆、烛光留言、管理凭证移转及撤回通过；临时记录已删除。
- `browser_feel.py`：三秒预选与取消、手动接管、收起冻结 4.2 秒、两岁四选一、七岁三选一、零岁与十二岁结局通过。此次快进到两岁约 3.4 秒，包含新增经历过程；不沿用 v3.1 的两秒结果。
- `browser_edges.py`：六档速度、无效导入保留进度、导入内容转义、浏览器存储不足时导出恢复通过。

`npm test` 最终 37/37 通过，约 503 秒。新增六项领域与动画控制器测试覆盖年龄、共用额度、资格重验、全地点路径、暂停/取消/单次回调和 500 条含小镇活动的完整人生。原有 30,000 条混合世界人生、217 地区、71 种被记录选项判定键、1,736 条风险曲线及 300,000 次寿命抽样继续通过；不表示覆盖原站所有隐藏规则。
