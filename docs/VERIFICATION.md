# 验收记录

环境：2026-10-25，Node.js 24，Chromium 145（Playwright）。

## 规则与数据

`npm test`：8 项测试通过。包含真实数据覆盖与汇总值排除、固定种子复现、50,000 次抽样的分布校验、选择时冻结、所有里程碑选项、经济状态变化与畸形档案拒绝。1,000 段人生均结束，期间每步通过状态验证。

`npm run build`：静态资源生成，内容摘要写入 `dist/version.json`。

## 浏览器验收

- 1440×1000 桌面：初始页、世界数据搜索、出生登记、人生选择、专注切换、刷新恢复、完整人生结束与纪念页。
- 留言保存后导出 JSON，核对内容；导出 PNG 人生卡片；档案导入与未完人生恢复。
- 390×844 手机：主页、出生与游戏；无横向溢出。
- 浅深色模式、自动模式、暂停与加速、出生种子分享、关闭选择窗后再打开。
- 页面控制台与运行时无错误。

## 部署

独立 Docker Compose 项目 `birth`，Nginx 静态托管，宿主机回环端口 8086，Instabox HTTPS 公网入口。上线后检查 `/healthz`、静态资源、内容摘要和 HTTPS 浏览器主流程。现有服务的容器 ID、运行状态、重启计数在部署前后对比。

## 已知范围

存档为浏览器本地数据，不能在不同域名间自动同步；更换设备需要导出导入。分享种子重现出生身份，不分享整段选择过程。规则和静态统计简化了世界，不代表真实个体人生预测。未提供原站的公共纪念馆和社交后台。
