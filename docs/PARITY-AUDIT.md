# 与 1in8b.life 的一致性审计

核对日期：2026-10-25，Asia/Shanghai。参考入口：[原站英文版](https://1in8b.life/en/)。受测实现：BIRTH 2.1.0。

**结论：未通过“一模一样”的验收。当前项目是独立实现，功能测试通过不能证明与原站等价。** 没有原站授权源码、完整事件和后端规则，无法验证所有隐藏分支，也不能保证后续更新始终一致。

## 证据与方法

用 Chromium 在 1440×1000 视口检查原站首页、历史设置、出生、游戏控制、18 岁消费面板和结局。选择 30 分钟、16 倍速、自动模式，实际运行一段人生至 79 岁结局；未使用修改年龄或读取私有接口的方法。结束画面显示 2026—2105。

走查使用独立浏览器，启用 DNT/GPC，并拦截非 GET/HEAD/OPTIONS 请求；没有向原站发布、留言或购买。检查公开玩法文档与政策；付费内容仅按公开说明记录，未声称已测。原站截图和观察文件保存在本次工作的本地输出目录，没有作为本项目代码或素材分发。

年龄采样器在结尾曾读到隐藏页面中的“18 岁”，该值不代表角色年龄回退。79 岁结局由可见结尾画面确认。该次走查只覆盖一条人生路径，不能据此推断所有国家、年代、选项或结局。

## 本轮修复与测试的含义

修复了缺失资产/职业字段仍可导入、错误等待状态造成卡住、大量交易使存档超出读取上限，以及跨设备档案遗漏公开纪念管理凭证的问题。新增 HTTP 边界、并发点灯、5,000 次交易、跨浏览器撤回、存储额度耗尽和导入文本转义测试；详见 [验收记录](VERIFICATION.md)。

这些测试检查本项目是否自洽、可恢复和能部署。它们没有使用原站的输出作为逐步规则判定标准，因此不是原站等价性测试，也没有给出虚假的一致率。

## 达到严格一致还需要什么

需要确定一个固定的原站版本，并取得可部署的授权源码、数据、素材及所需服务配置；再在相同输入下逐步比较状态、事件、存档、API 响应和桌面/移动画面。没有这些基准时，公开页面走查只能得到有限的行为样本。

官方隐私政策说明源码仓库为私有，条款保留代码、文字和图片的权利。本仓库 MIT 许可只适用于本项目自己的代码，不授予原站内容的复制或再分发权。
