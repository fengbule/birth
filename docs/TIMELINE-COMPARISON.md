# 连续时间线与原站实测（v5）

日期：2026-10-26；参考站实际显示 v0.8.40 beta。入口：https://1in8b.life/zh-hans/ 。按公开页面复现，没有原站源码。原站浏览器仅允许 GET / HEAD / OPTIONS，未发布、留言或购买。

## 原站实际观察

- 整数年龄之间连续推进，同岁里的多条叙述在不同时间出现，无需逐条按继续。人生纪录最新在上，行内显示完整叙述，点行可加星。
- 初生时一条出生记录，之后有疫苗等年内事件。一次 30 分钟、16× 的中非女性样本，约 457ms 出现初生事件，1927ms 到一岁，2544ms、3086ms 又出现一岁内记录，约 4496ms 到两岁抉择。这是随机样本，不是所有国家的固定时序。
- 两岁四项气质，七岁三个具体兴趣，十二岁是否继续学业。中非样本十六岁高中、十九岁大学；同年可以继续遇到专业或其他卡片。
- 收起未决抉择后年龄停止；重新展开并选择后回到连续时间流。自动选择先预览约三秒，手动点击立即接管，标题可取消当前预览。
- 桌面三栏为 320 / 580 / 340px，间距 20px，1440px 视口左右各留 80px；场景约 580×180px。手机顺序为场景、简要状态、记录、重心、完整状态、身份、家人与统计。年格按当地预期寿命向上补齐十年，超出后扩展。

## 改动与实测

撤下 v4 小镇、走路等待与逐段继续。新局持久化年内时钟，按阶段显示事件；同龄选择结果也按年内位置排序。新增记录保留旧行的展开状态。暂停、切倍速和刷新保留进度，未出现的记录不会提前显示。

整理 172 个公开国家详情页的数值事实，今日新局与国家面板使用男女寿命、婴儿/五岁前死亡率、经济社会指标、城市与宗教比例。数据经过页面四舍五入，不是隐藏规则表。修复「14亿2,258万」的复合单位解析，覆盖人口合计约 80.79 亿。金额按中国大陆物价换算人民币，见 [数据署名](../DATA-SOURCES.md)。

真实 Chromium 对原站与实现分别执行 1440、390 两种宽度的出生、倍速、年内出现、两岁四选项、收起保持 2300ms、重新展开、选择后继续；四次走查均无页面运行错误。两边独立抽取身份，几个操作通过不能推断全规则等价。

实现端 390、1440 实测自动预览 3031 / 3047ms，手动接管 47 / 31ms，收起保持 4200ms，快转至首个两岁选择 2578 / 2531ms。均使用真实浏览器时钟与可见操作，时间包含浏览器调度。未注入原站状态、随机数或时间。

12 个地区的完整人生真实点击共处理 239 张抉择卡，消费、延迟岗位/对象/国外机会、面板冻结、收藏重载、结束、二次跳过及重播通过。它验证实现的稳定性，不是两站运行相同种子的比较。

六种宽度 360 / 390 / 768 / 1280 / 1440 / 1920 无横向溢出，手机顺序、桌面栏位、键盘收藏、刷新、深色主题通过。原站和实现另采集首页、出生、游戏、菜单，两个视口共八组截图；采集成功不等于视觉验收通过。

## 剩余差异

- 叙述、题库、触发条件与概率仍独立实现，阶段、专业与职业池尚未覆盖原站全部内容。中非学龄差异仅做了局部适配。
- 美术是本项目绘制的 SVG 场景，人物、纹理和动画并非原站资产，不能称为逐像素一致。
- 寿命拟合、收入、财务、家庭和迁居不是原站隐藏模型；世界均值曲线标为估算。国家资料的显示精度不等于内部精度。
- 历史世界范围、未来模型、币种切换、前世之家、多语言、官方后端和付费功能仍有差异或缺失。

**结论：已修正本轮反馈中的主要流程与排列问题，尚未通过 1:1 等价验收。** 测试数量不作为一致率。
