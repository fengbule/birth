## 规则与数据

本轮 `npm test`：24 项全部通过、零失败，约 90 秒。覆盖出生确定性、50,000 次抽样、真实统计和汇总值排除、全部选择、经济状态、畸形导入、旧存档、主动活动、迁居和人生停顿。

基础与扩展各模拟 1,000 段完整人生，另运行 10,000 段混合年代压力样本，共 12,000 段。每步检查状态，定期 JSON 往返重载，均能结束。压力样本覆盖 217 个出生地区、63 个选择分支，成功执行 357,812 次活动、10,732 次迁居。前 217 个样本逐国固定，后续按出生/人口权重抽样；这些数字不是原站覆盖率。

5,000 次交易检查净资产守恒、事件上限 2,000、记录保留、事件 ID 唯一及存档重载。拒绝缺失资产/职业字段、非法小数年份、未来事件年龄与不可能的等待状态。30/60/90 分钟默认 60，旧档 5/15 分钟兼容。

今日截面覆盖 2023 年 217 地区；历史有效覆盖为 1970 年 216 地区、1990 和 2010 年各 217 地区。2050 是明确标注的游戏情景，任意世界从五个受支持世界中选择，未扩充为原站全部历史年份。

API 测试覆盖来源校验、发布字段、公开响应无管理凭证、点灯去重、留言、数据库重开、撤回鉴权和级联删除；25 条同毫秒记录分页完整，备份完整性与数量一致。HTTP 边界包括损坏 JSON、内容类型、16 KB 限制、非法来源、分页、路径穿越和 SQL 字符串；12 个同访客并发点灯只累计一次。超过结束年龄的公开事件被拒绝。

## 浏览器验收

本地与 Instabox HTTPS 公网四组浏览器测试均已通过，页面运行时错误为空：

- 深度流程：1990 历史起点、私人停顿、家庭、活动、投资、职业、迁居；公共纪念发布、读取、点灯去重、留言、匿名无撤回权限，以及私有档案转移至另一浏览器后撤回。

重跑入口：`tests/browser_smoke.py`、`tests/browser_deep.py`、`tests/browser_edges.py`、`tests/browser_presentation.py`。深度流程使用固定出生种子，公开测试记录在清理阶段撤回；新版布局和边界流程不写公共数据。截图及私人测试档案在本地输出目录，不入仓库。
