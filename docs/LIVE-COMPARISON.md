# 原站与部署版：实际操作对照

日期：2026-10-25（Asia/Shanghai）。浏览器直接渲染的原站为 **v0.8.38 beta**；检索工具缓存显示 v0.8.37，不以缓存版本代替实测。参考：[英文入口](https://1in8b.life/en/)、[简体中文](https://1in8b.life/zh-hans/)。初始受测部署为 BIRTH 3.0.0，随后修复版本为 3.0.1。

**结论：未通过原站等价验收，已观察到多项实质差异。** 这不是仅因隐藏规则未知而保留结论，也不能用本项目自身的压力测试通过来替代对比。

## 怎样实际操作

使用同一 Chromium 147，桌面 1440×1000、手机 390×844、浅色、中文语言和 Asia/Shanghai 时区。两边均通过页面选择今日、出生人数抽样、30 分钟、实际家乡中国；手机使用独立新上下文。另实际进入英文原站核对开局。截图、可见控件、布局尺寸与操作结果保存在工作输出目录。

两边独立抽取身份：原站桌面角色出生于印度，部署版角色出生于加拿大。因此不以两个人物的寿命、现金、随机事件和状态值不同来直接判定算法差异；页面结构、控件有无和操作行为可以对照。没有向原站注入角色状态、修改年龄、读取应用源码或使用假时钟。

原站从出生实际走到 65 岁结局（2026—2091），期间用 16 倍速、自动与可见选项继续，手动检查成年消费、求职、借款与事件。部署版同样实际走到 92 岁结局（2026—2118）。这两条人生不能视为相同输入的确定性复现。

原站仅允许 GET/HEAD/OPTIONS，启用 DNT/GPC；未发帖、留言、付款或对外分享。消费和借款是该浏览器里的虚构游戏操作。公共纪念写入只测试自行拥有的部署，不据此声称原站公共服务等价。

走查中遇到的定位器或动画等待超时，经重新查看可见界面后继续操作；这些自动化问题不计为原站产品缺陷，也没有使用强制点击绕过遮挡。

## 实测发现与处理

| 对照项 | 原站实际操作结果 | BIRTH 3.0.0 | 3.0.1 处理 |
| --- | --- | --- | --- |
| 首页概率条 | 印度与汇总其他地区均达到条轨上限 | 其他地区误用原始百分比，条长偏短 | 使用相同比例尺并限制至条轨上限 |
| 首页标题字重 | 概率卡标题 20px、600 | 21px、700 | 对齐尺寸与字重 |
| 婴幼儿专注 | 六岁前无可操作的年度专注控件 | 下拉框因样式优先级仍显示 | 修复隐藏规则，出生后回归检查 |
| 出生同行者 | 登记末尾展示四个同时出生的人 | 出生页缺少，游戏中才显示 | 登记页补四个同行者 |
| 年格数量 | 印度样本 80 格；英文尼日利亚样本 60 格 | 固定 110 格，卡片过高 | 按当地寿命和已走年岁调整，补寿命标记；幸福热图仍不同 |
| 收藏记录 | 点击行展开，再点击星标；支持收合 | 点行无操作，仅常显小星标 | 行展开、键盘操作、独立收藏按钮与按下状态 |
| 抉择窗口 | 桌面约 560px，可先收起再展开，卡内可交给自动 | 700px、模糊背景，缺少卡内自动入口 | 缩窄、去背景模糊，明确收起入口并补自动入口 |
| 手机面板 | 六个信息面板可收合与展开 | 全部固定展开 | 增加六个折叠控件，键盘与多次重绘后回归 |
| 手机尺寸 | 主内容两侧各 16px，工具按钮约 40px 高 | 两侧 12px、按钮 32px，标题偏小 | 调整留白、按钮高度及面板标题 |
| 画面与文本 | 地区、城乡、家庭及出生事件影响场景和记录；本轮手机另见早产与洪灾叙事 | 独立 SVG、较少的出生字段与事件 | **未对齐**：手机留白修复不等于画面或内容相同 |
| 首个童年抉择 | 2 岁出现四选一气质事件 | 先到 5 岁私人问答，首个抉择 6 岁三选一 | **未对齐**：不是同一套童年规则 |
| 出生资料 | 有月份、具体地名、父母职业、兄弟姐妹、宗教；印度样本另有种姓 | 资料较少，主要是国家、城乡、家境、父母年龄 | **未对齐**：不能伪造为已复现 |
| 成年消费 | 展开更多项目，含找对象、四类职训、消费、生活方式、借款等 | 另一套年度活动与两类投资 | **未对齐** |
| 求职 | 实际操作后显示两年冷却，随后出现具体岗位邀约 | 求职活动与职业经验模型不同 | **未对齐** |
| 借款消费 | 样本现金 630，消费 699 后显示负债 69（页面体感金额） | 没有同样的借款消费流程 | **未对齐**；金额不是金融建议 |
| 条件事件 | 走查中见债务、照护、兴趣、退休、宠物等；选项数有 2、3、4、6 | 固定核心节点和独立扩展场景，三选一为主 | **未对齐**，固定节点数量不是原站覆盖率 |
| 自动抉择 | 会先展示将选的选项，停留后继续，也影响年度重心 | 直接代选，重心行为不同 | **未对齐** |
| 币种、语言 | 中文页面本轮有 9 个币种选项；英文入口和多语言导航可用 | 中文及 PPP 国际元 | **未对齐** |
| 死亡纪录 | 全页纪录、死因、人生纹理、最幸福年份、职业与照护回顾等 | 简化纪念弹窗 | **未对齐** |
| 结尾与收藏 | 实际重播，跳过按钮需进一步确认；另有影像与照片预览入口 | 简化结尾，单次跳过，PNG 和 JSON | **未对齐**；付费内容未购买测试 |

统计来源、地区集合、历史范围和生命表也有差异，详见 [完整审计](PARITY-AUDIT.md)。本轮只修复可从页面直接确认且不需要编造统计的展示与操作问题，没有声称以少量样本重建了原站模型。

## 可重复的浏览器对照

```sh
# 与本地服务对照；也可把 BIRTH_TEST_URL 指向自己的部署
python tests/browser_compare.py
```

使用 `CHROMIUM_PATH` 指定已安装浏览器，`BIRTH_TEST_URL` 指定部署版，`BIRTH_TEST_OUTPUT` 指定输出目录。默认生成 `test-results/comparison/comparison.html`、`comparison.json` 以及截图。HTML 支持并排、叠加与透明度滑杆；JSON 记录视口、矩形尺寸、字号、字重、控件与运行时错误。截图留在输出目录，不提交原站素材。

自动对照采集首页、出生、游戏和工具菜单，共两个视口八对画面；65 岁完整人生、消费与借款为本轮交互走查记录，不冒充自动脚本覆盖范围。脚本采集成功不等于一致性通过，不输出未经证明的像素一致率或规则一致率。

修复回归入口为 `tests/browser_presentation.py`；测试包括隐藏专注、四个同行者、概率条、年格、行展开收藏、手机折叠、抉择收起和卡内自动。3.0.1 更新后的公网已重跑四套应用回归和两站八对采集，页面运行时错误为空；人工核对后仍判定不等价。工作输出 `output/birth-live-compare/report.html` 包含五组深度走查证据和八组新版公网对照，可并排或叠加查看。上线事实与公网结果见 [验收记录](VERIFICATION.md)。
